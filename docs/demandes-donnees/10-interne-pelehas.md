# Pelehas : demandes et attributions

*Service logement*

Fiches : #935, #995.

## Texte à envoyer

Compléter les passages entre crochets.

```text
Objet : extraction annuelle de Pelehas pour l'observatoire territorial

Pour alimenter les indicateurs logement de l'observatoire, merci de produire chaque année (et une fois pour l'historique depuis 2015) une extraction agrégée de Pelehas :

1. Demandes actives au 31 décembre ayant Ivry en premier choix
   - total ; par typologie demandée (T1 à T5 et plus) ; par ancienneté (moins d'un an, 1 à 3 ans, plus de 3 ans) ; par composition du ménage ; par tranche de revenus
2. Demandes enregistrées dans l'année, et demandes radiées (pour attribution / pour un autre motif)
3. Attributions de l'année (baux signés)
   - total ; par typologie ; par réservataire (Ville, État, Action Logement, bailleur) ; en QPV / hors QPV
4. Publics prioritaires (DALO, accords collectifs) : demandes et attributions

Format : CSV, colonnes annee ; mesure ; modalite ; valeur. Aucune donnée nominative.
Contact Observatoire : [nom, courriel]
```
