# Millésime : impayés, aides et accès aux droits

*CCAS*

Fiches : #938, #939, #862.

## Texte à envoyer

Compléter les passages entre crochets.

```text
Objet : extraction annuelle de Millésime pour l'observatoire territorial

Pour alimenter les indicateurs de cohésion sociale de l'observatoire, merci de produire chaque année (et une fois pour l'historique disponible) une extraction agrégée de Millésime :

1. Impayés
   - demandes d'aide pour impayés et aides accordées, par motif (loyer, énergie, eau) : nombre et montants
   - dossiers FSL instruits
   - signalements ou saisines reçus (bailleurs, CCAPEX, fournisseurs d'énergie), s'ils sont enregistrés
2. Accès aux droits
   - sollicitations ou rendez-vous par type de démarche (RSA, C2S, retraite, logement, autre)
   - domiciliations actives au 31 décembre
   - droits ouverts ou orientations réalisées à la suite d'un accompagnement (approche locale du non-recours)

Si l'adresse est géocodée : mêmes comptages par quartier.
Format : CSV, colonnes annee ; mesure ; modalite ; valeur. Aucune donnée nominative, cases de moins de 5 personnes masquées.
Contact Observatoire : [nom, courriel]
```
